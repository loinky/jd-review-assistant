# 京东评价助手

面向个人使用的 Chrome Manifest V3 扩展，用于减少京东评价流程中的页面跳转和评论资料整理操作。

## 当前能力

- 在京东“待评价订单”页面识别当前页订单，并只显示一个“按顺序自动评价并发表”按钮。
- 点击一次后按当前页面顺序依次处理商品；上一件发表并返回列表后，自动打开下一件。
- 当前队列全部发表完成后，自动关闭评价标签页。
- 记录订单、商品和评价详情链接，打开评价详情页。
- 在评价详情读取真实商品链接，并提供“打开商品并读取评论”入口。
- 在商品详情页读取当前展示的评论文字、标签和评论图片 URL。
- 将 `300x300` 评论缩略图转换为 `1080x1080` 图片地址。
- 从评论中提取配料、甜度、口感、材质、做工、尺寸、操作和续航等具体信息。
- 内置 100 种自然开头与收尾组合，并从商品详情评论中筛选、清理一小段具体体验混合生成，减少重复和模板感。
- 商品没有详情链接时，结合商品名称、订单规格和品类生成有针对性的文案，不再使用“符合预期”式通用模板。
- 自动填写评价文案，并设置商品评分和物流服务评分为五星。
- 自动读取并上传当前评论图片中的前 3 张。
- 没有评论图片、没有图片上传入口或图片读取失败时，跳过图片并继续发表。
- 商品采集和上传完成后自动切回评价详情页。
- 自动点击“发表”，成功后返回待评价列表。
- 仅在打开评价页、打开商品页、切回评价页和打开下一件等页面切换前随机等待 3-5 秒；填写、评分、上传和发表连续执行。
- 没有商品详情链接时使用通用评价无图发表；仅服务评价时自动完成服务五星并发表。
- 可按商品目录下载当前读取到的评论图片。
- 所有任务数据只保存在 `chrome.storage.local`。

点击“按顺序自动评价并发表”即会触发当前页商品的真实发表操作，不再提供第二次确认。使用前应确认生成内容和图片符合实际体验，并确认拥有图片的使用权。

## 安装

1. 在 Chrome 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择下载或克隆后的项目目录。
5. 打开 [待评价订单](https://club.jd.com/myJdcomments/myJdcomment.action?sort=0)。

修改代码后，在扩展管理页点击本扩展的“重新加载”，再刷新京东页面。

## 检查

```bash
pnpm check
pnpm test
```

项目没有第三方依赖，不需要执行安装命令。

## 后续接口

当前任务保存在 `jdReviewAssistantTask`，包含订单、商品、评论文字和评论图片 URL。后续本地 MCP 服务可以直接围绕这份结构提供读取、生成评价和回填工具。
